# Пример проекта книги bgen

Скопируйте этот каталог и используйте как основу для новой книги.

## Запуск

    bgen.py build .
    bgen.py stat .

## Структура

    config.yaml          — конфигурация проекта (все параметры с комментариями)
    img/cover.jpg        — обложка (положите любой .jpg)
    body/                — весь текст книги

## Как собирается текст

Все `.md` файлы в `body/` **рекурсивно** обходятся, сортируются
лексикографически по полному пути и склеиваются в один документ.
Такой обход отображается `ls`

- Один файл в `body/` — рассказ в одном файле.
- Много файлов и подпапок — большая форма.
- Разницы в механике сборки нет.

Пример многофайловой структуры:

    body/
      000_epigraph.md         # эпиграф книги
      010_partone.md          # ## Часть первая
      020_parttwo.md          # ## Часть вторая
      030_chapter/
        00_scene.md          # ### Сцена
      040_chapter/
        00_scene.md

**Порядок — лексикографический по полному пути** (Python сортирует по code
point, не по локали). Для предсказуемого порядка используйте ASCII-имена
с ведущими нулями (`00_`, `01_`, `09_`, 0a_, 0b_...). Кириллица в именах может дать
неожиданный порядок. В числах лучше оставлять пропуски, чтобы было проще вставлять новые части.

## Особенности

**Не смешивайте текст и подсекции в одной секции.** Если в главе есть
подглавы (`###`), текст между `##` и первым `###` писать нельзя — XSD
поругается на смешанную секцию. Либо текст до `##`, либо глава состоит
только из подглав. Это ограничение формата FB2, многие читалки всё
равно отобразят такой файл, но это уже на ваш страх и риск.

## Специальная разметка

Примеры **всех** конструкций (эпиграфы, аннотации, фронтиспис, subtitle,
астеризм, стихи, кавычки, сноски, ссылки, таблицы, списки) — в `body/99_syntax_demo.md`.
Соберите пример (`bgen.py build .`) и посмотрите `output/`: там видно, во что превращается каждая
конструкция.

## Обложка

Положите любой `.jpg` в `img/cover.jpg`. Если файла нет — сборка
продолжится без обложки (с предупреждением).

## Ограничения FB2

- **Многострочный код** — не поддерживается схемой; Pandoc выдаёт серию
  `<p><code>`.
- **Разрыв строки внутри абзаца** — невозможен по схеме.
- **Сложные таблицы** (colspan/rowspan) — не поддерживаются Pandoc.
- **Смешанные секции** (текст + подсекции) — XSD не пропускает.
