# Пример проекта bgen

Скопируйте этот каталог и используйте как основу для новой книги.

## Запуск

    bgen.py build .
    bgen.py stat .

## Структура

    config.yaml          — конфигурация проекта
    _annotation.md       — аннотация книги (опционально)
    img/cover.jpg        — обложка (положите любой .jpg)
    body/                — весь текст книги

## Как собирается текст

Все `.md` файлы в `body/` **рекурсивно** обходятся, сортируются
лексикографически по полному пути и склеиваются в один документ.

- Один файл в `body/` — рассказ в одном файле.
- Много файлов и подпапок — большая форма.
- Разницы в механике сборки нет.

Пример многофайловой структуры:

    body/
      00_epigraph.md         # эпиграф книги
      00_partone.md          # ## Часть первая
      01_parttwo.md          # ## Часть вторая
      chapter_0/
        00_scene.md          # ### Сцена
      chapter_1/
        00_scene.md

## Уровень заголовка = уровень вложенности

- `##` — заголовок верхнего уровня (часть/глава).
- `###` — вложенная глава/сцена.
- `#` (первый уровень) в `body/` не использовать: заголовок книги берётся
  из `metadata.title` в `config.yaml` и попадает в `<book-title>`.

## Специальная разметка

### Эпиграф (книги или главы)

    ::: {.epigraph .book}
    Текст эпиграфа книги.

    — Автор
    :::

    ::: {.epigraph}
    Текст эпиграфа главы.

    — Автор
    :::

- Эпиграф книги: в `body/` до первой секции.
- Эпиграф главы: внутри главы после заголовка.

### Стихотворение

    ::: {.poem}
    Строка первая
    Строка вторая
    Строка третья

    Вторая строфа
    Ещё одна строка
    :::

Строфы разделяются пустой строкой. Каждая строка — `<v>` в FB2.

### Астеризм (сильный разделитель)

    ::: {.asterism}
    :::

В FB2 даёт `<p>* * *</p>`.

### Слабая пустая строка

`---` отдельной строкой (с пустыми строками до и после) → `<empty-line/>`.

## Что удалить перед публикацией

`body/99_syntax_demo.md` — это пробник синтаксиса. Он специально назван
`99_`, чтобы не мешать вашим файлам (`00_`, `01_` и т.д.). Соберите книгу,
посмотрите, как элементы выглядят в FB2, и удалите файл перед публикацией.

## Обложка

Положите любой `.jpg` в `img/cover.jpg`. Если файла нет — сборка
продолжится без обложки (с предупреждением).

## Ограничения FB2

- Многострочный код: не поддерживается схемой FB2, Pandoc выдаёт
  серию `<p><code>`.
- Разрыв строки внутри абзаца: невозможен по схеме.
- Сложные таблицы: могут не конвертироваться, тестируйте на своих данных.
- `#` (первый уровень) не используйте в `body/`.
