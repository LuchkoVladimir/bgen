# BookGenerator - bgen

Генератор цифровых книг из Markdown. Собирает FB2/EPUB/DOCX/TXT),
дополняя Pandoc постобработкой для FB2 и TXT: эпиграфы, аннотации, кавычки, фронтиспис и т. д.
То, что Pandoc не умеет или делает невалидно.

Основное назначение программы - генерация электронных книг. То есть сюда не входит spellcheck,
поиск повторов и прочее в таком духе.


## Выбранные форматы

### Входной

**pandoc-markdown** - стандарт для pandoc. Удобен для представления текста и хранения в VCS (например GIT).
Для целей лучшей поддержки FB2 используются fenced-div`s и spans формата.
Также поддержаны типографские символы через файл замен и span. Подробности - в примере проекта.


### Выходные

- **FB2**     - стандарт для русскоязычной прозы. Но не мировой стандарт, возможно поэтому pandoc его формирует
с очень большими проблемами. Ради получения корректного FB2 bgen изначально и разрабатывался. Но в итоге
было решено добавить и другие форматы.
- **EPUB**    - мировой стандарт формата электронной книги, поэтому он взят вторым к FB2. Вроде бы здесь pandoc делает
всё правильно и постобработка не требуется.
- **DOCX**    - формат для отправки редактору/корректору/издателю.
- **TXT**     - ну, как будто, просто должен быть. Это база.


#### Не поддержан

**PDF**     - изначально было желание генерировать PDF для печати. Ведь было бы же здорово - жмакнул, и можно печатать,
но похоже на то, что макет для печати это, во многом, ручная вёрстка в соответствующем инструментарии. Поэтому в эту
сторону развитие не пошло.


## Требования

- **Python 3.9+** (для `ET.indent`; на более старых версиях форматирование
  XML пропускается с предупреждением).
- **Pandoc** в `PATH`. Проверено на 3.1.3.
- **PyYAML**: `pip install pyyaml`.
- **lxml**: `pip install lxml` (для XSD-валидации FB2).
- **panflute**: `pip install panflute` (для python-фильтра для pandoc).


## Установка

Скачиваете всю директорию **bgen** и запускаете из неё **bgen.py**. Внутри директории есть всё необходимое для
работы, за исключением указанных выше требований по зависимостям.
**project_sample** можно использовать как шаблон для проекта своей книги.


## Быстрый старт

- **project_sample** содержит пример проекта книги.
- **project_sample/readme.md** - описание проекта книги и как с ним работать.

    cp -r project_sample mybook
    cd mybook

Почитать readme.md
Отредактировать config.yaml и текст в body/

    ./bgen.py build <path_to_project>
    ./bgen.py stat <path_to_project>

Результат - output/book.fb2.

    bgen.py --help
    bgen.py build <path> [--only fb2]   # собрать книгу
    bgen.py stat <path>                 # статистика текста (файлы, знаки, слова)

stat - только объёмные метрики. Анализ стиля (повторы, частотность) - вне bgen (отдельный инструмент).

Примеры разметки - в project\_sample/body/99\_syntax\_demo.md
Соберите пример и посмотрите результат.
